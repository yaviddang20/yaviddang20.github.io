## Adding Images

To add images to this project page:

1. Create an `images/` folder inside `eecs206a/`
2. Add your images there
3. Update the image paths in `index.html` using:
   ```html
   <img src="{{ '/eecs206a/images/your-image.png' | relative_url }}" alt="Description">
   ```

## Customization

Edit `index.html` to update:
- Project description
- Methodology steps
- Results and images
- Technology stack
- Links and resources
